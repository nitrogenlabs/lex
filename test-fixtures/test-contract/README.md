# Installed public test contract

Copy this directory outside every checkout's node_modules ancestry, set its `@nlabs/lex` dependency to an immutable built archive, then install with lifecycle scripts disabled. No Vitest dependency, alias, symlink, or installed patch is required. React/DOM and declaration packages are ordinary consumer peers. Use `npm install --install-strategy=nested --ignore-scripts` for a nonhoisted graph. Yarn Classic workspaces may use `nohoist: ["**/vitest", "**/vitest/**"]` to expose the runner identity regression; do not include `**/@vitest/**`, which hits a Yarn Classic linker invariant in the current lint dependency graph.

Run `node scripts/verify-test-contract.mjs ABSOLUTE_FIXTURE ABSOLUTE_EVIDENCE` from the owner after installation. Supply any environment/network guard required by the calling task. The script invokes only installed public Lex/compiler binaries, checks full NodeNext and Bundler declarations, verifies expected invalid types, runs static-import hoisting, timers, real React DOM matchers, coverage and negative controls, and checks actual `lex create tsconfig` declaration-only output. The globals entry only supplies types; `globals: true` remains required at runtime. The runner versions and dependency locations are saved with command exits.
