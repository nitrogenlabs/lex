# Public Playwright contract

Install this fixture outside all checkout dependency trees. It declares Lex and
ordinary Node declaration peers, with no direct Playwright runner dependency,
source alias, symlink or installed patch. Before publication, producer qualification
may install the exact frozen reviewed archive into this disposable fixture only.
Application adoption uses the verified registry release.

Run `node scripts/verify-playwright-contract.mjs ABSOLUTE_FIXTURE ABSOLUTE_EVIDENCE`
from the owner after installation. It compiles public aliases and callback inference
in strict NodeNext and Bundler modes, checks exact negative type failures, and runs
the installed public Lex Playwright command with no outbound requests. Qualify both
npm nested and Yarn Classic workspaces with Playwright dependencies kept beneath
Lex. A hoisted-only bare runner import is not an equivalent contract.
